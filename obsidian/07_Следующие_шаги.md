# Следующие шаги

## 0. Сначала починить дерево

Полный прогон показал, что связей почти нет: [[08_Проверка_реальных_деревьев]]. Этот шаг важнее остальных.

## 1. Запустить полный прогон

Нужно:

1. Запускать по одному кейсу и с `SEARCH_MAX_PARALLEL=3`, иначе Tavily блокирует ключ.
2. Проверить остаток кредитов Tavily: в этой сессии ушло несколько сотен, тариф на 1000 в месяц.
3. Исправить в `.env` значение `STAGE_CLAIM_EXTRACTION=vmock`. Такого режима нет, сервер с ним не запускается.

Команды, сначала прежний режим:

```bash
STAGES_DEFAULT=real STAGE_CLAIM_EXTRACTION=real STAGE_SOURCE_SEARCH=real STAGE_STANCES=real TRACE_SEARCH=off npm run eval:pipeline -w backend -- --label baseline
```

```bash
STAGES_DEFAULT=real STAGE_CLAIM_EXTRACTION=real STAGE_SOURCE_SEARCH=real STAGE_STANCES=real TRACE_SEARCH=on npm run eval:pipeline -w backend -- --label traces
```

Итог появится в `tmp/eval/<label>/summary.md`. Из-за шума поиска лучше сделать по 3 прогона на режим.

## 2. Решения по результатам

- Включать `TRACE_SEARCH` только если доля верных корней выросла, а контрольные факты не пострадали.
- Если ложно ранние страницы останутся, добавить проверку корня: он должен содержать само утверждение, а не только тему.
- Пересмотреть бюджет: в большинстве кейсов поиск остановился по бюджету. Сначала отсеивать слабые следы, потом расширять лимиты.

## 3. Эталон дерева

Этапу 05 нужен `eval`. Собрать 30–50 молдавских историй с деревьями, проверенными вручную. Считать Root, Edges, Ancestry и Depth.

## 4. Показ в отчёте

Нужна договорённость троих о контракте:

- блок «Установлено, открыто, не проверено»;
- подпись «самая ранняя из найденных»;
- список следов, которые не удалось проверить.

## 5. Для целей программы

- Показывать приём манипуляции: поддельный сайт, клон издания, украденное имя.
- Проверить, как отчёт цитирует сексистские формулировки: принцип нейтрального тона требует не усиливать оскорбления.
- Обсудить с учреждениями формат выгрузки хронологии для ответа и обучения.

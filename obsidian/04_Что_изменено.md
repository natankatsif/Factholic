# Что изменено

Всё новое поведение включается флагом `TRACE_SEARCH=on`. По умолчанию стоит `off`, прежняя логика работает как раньше.

## Этап 04: поиск

| Файл            | Изменение                                                             |
| --------------- | --------------------------------------------------------------------- |
| `traces.ts`     | Новый: следы, абзацы про утверждение, запросы без чисел               |
| `copies.ts`     | Новый режим `traceCopies`: первый круг по языкам и до 2 кругов добора |
| `copies.ts`     | Ссылки берутся только из абзацев про утверждение                      |
| `copies.ts`     | Ранние и найденные по следу копии защищены от вытеснения              |
| `copies.ts`     | Вместо фильтра чисел порог совпадения 0.6 для ранних копий            |
| `same-event.ts` | Другое число больше не считается другим событием                      |
| `types.ts`      | Новые необязательные типы `Trace`, `TraceReport`, поле `traced`       |

Правила против шума появились после первого живого прогона:

- Следы открываются только от копий с совпадением от 0.5.
- Источником считается имя собственное до 4 слов.
- Страницы LinkedIn исключены из поиска копий.

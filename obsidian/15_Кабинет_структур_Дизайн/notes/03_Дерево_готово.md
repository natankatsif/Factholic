## Когда показывается

Проверка закончена. **Это базовый экран холста.**

## Что делает сотрудник

- Холст двигается и масштабируется, «Показать всё» вписывает дерево.
- Клик по узлу открывает карточку публикации, клик по связи открывает карточку связи.
- Узел можно перетащить, данные от этого не меняются.
- «Следить» ведёт в настройки, «Не сейчас» скрывает предложение.

## Данные

- `GET /api/org/checks/:id`
- `ProvenanceTree`, `FactCheck`
- `tree.edge.added`, `tree.root.changed`, `check.finished`

## Проверить

- [ ] Корень подписан «Самая ранняя из найденных».
- [ ] Сплошная линия подтверждена, пунктир вероятен, оранжевая с изменениями.
- [ ] Публикации без связи стоят отдельной группой, это не ошибка.
- [ ] Предыстория приглушена и не связана с корнем.
- [ ] Экран с `?fixture=tree-ready` совпадает с [картинкой](../screens/03-tree-ready/reference.png).

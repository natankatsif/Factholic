## Шрифт

Nunito. Он уже подключён в проекте, в Tailwind это `font-sans`.

| Назначение         | Размер | Насыщенность |
| ------------------ | ------ | ------------ |
| Заголовок страницы | 34–36  | 900          |
| Заголовок в панели | 19     | 900          |
| Название блока     | 15–17  | 900          |
| Основной текст     | 14     | 700          |
| Подпись, метка     | 12–13  | 700–800      |

## Компоненты

| Компонент           | Где виден  | Варианты                                                               |
| ------------------- | ---------- | ---------------------------------------------------------------------- |
| `TopBar`            | Все экраны | Обычная, с проверками, активная ссылка, кнопка отключена, меню открыто |
| `RunningChecks`     | 02, 13–16  | Одна проверка, несколько (`+1`), открытый список                       |
| `LeftMenu`          | 13–15      | Закреплено, поверх холста                                              |
| `PublicationNode`   | Холст      | Публикация, самая ранняя, разбор, предыстория, с изменениями, выбрана  |
| `CheckedTextNode`   | Холст      | Один вид                                                               |
| `MissingSourceNode` | Холст      | Один вид                                                               |
| `UnlinkedGroup`     | Холст      | Список без связи                                                       |
| `Edge`              | Холст      | Подтверждена, вероятная, с изменениями, новая, выбрана                 |
| `SearchProgress`    | 02, 09     | Открыт, свёрнут, с ошибкой                                             |
| `RightPanel`        | Холст      | Лента, настройки, пустая                                               |
| `FeedMessage`       | Лента      | С иконкой, предложение, уведомление, ошибка                            |
| `SidesBar`          | 14         | Полоска и счёт                                                         |
| `CheckField`        | 01, 10, 12 | Обычное, с текстом, отключено                                          |

## Состояния вопроса

| Статус      | Подпись          | Цвет         |
| ----------- | ---------------- | ------------ |
| `new`       | Только проверили | Синий        |
| `spreading` | Растёт           | Оранжевый    |
| `stable`    | Спокойно         | Серый        |
| `debunked`  | Есть разборы     | Фиолетовый   |
| `fading`    | Затухает         | Приглушённый |

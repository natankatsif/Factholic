# Кабинет структур: обзор

Статус: черновик для обсуждения. Код пока не написан.

## Зачем

Сайт для людей отвечает на вопрос «что с этим утверждением?». Кабинет для структур отвечает на другие вопросы:

- откуда пошла история;
- как она менялась;
- растёт ли она прямо сейчас;
- когда сотруднику стоит обратить внимание.

Это поддерживает цель №1: государственные учреждения могут лучше реагировать на цифровую дезинформацию.

## Для кого

| Роль                      | Что делает                                               |
| ------------------------- | -------------------------------------------------------- |
| Аналитик                  | Проверяет утверждения, ставит на слежение, читает дерево |
| Руководитель отдела       | Смотрит важные сигналы и готовые карточки                |
| Администратор организации | Управляет людьми и лимитами                              |

В первой версии хватит одной роли: сотрудник организации.

## Как выглядит кабинет

```text
┌───────────────────────────────────────────────────────────────┐
│ Верхняя панель: поиск утверждения, организация, профиль       │
├─────────────────────────────────────────────┬─────────────────┤
│                                             │ Правая панель   │
│  Холст                                      │ на всю высоту   │
│                                             │                 │
│  Здесь растёт дерево публикаций             │ Сообщения       │
│                                             │ о тезисе        │
│  ┌───────────────┐                          │                 │
│  │ Ход поиска    │                          │ Предложение     │
│  └───────────────┘                          │ следить         │
│                                             │                 │
│                                             │ Уведомления     │
└─────────────────────────────────────────────┴─────────────────┘
```

## Главный сценарий

1. Сотрудник вставляет текст или ссылку.
2. На холсте появляется проверяемый текст, затем начинается поиск.
3. Блок «Ход поиска» показывает, что сейчас делает система.
4. Публикации появляются на холсте, связи дорисовываются после разбора.
5. В правой панели приходит итог и вопрос: «Поставить тезис на слежение?».
6. Сотрудник включает слежение.
7. Когда история растёт, панель показывает уведомление, а на холсте подсвечивается новое.

## Правила

- Система показывает историю утверждения, а не вердикт.
- Корень называется «самая ранняя из найденных».
- Связь без доказательства показывается как вероятная.
- Следим за утверждениями и публикациями, а не за обычными людьми.
- Решение, отвечать ли публично, принимает человек.
- Система не предлагает скрывать, удалять или блокировать материалы.

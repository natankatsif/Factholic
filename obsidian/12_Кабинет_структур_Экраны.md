# Кабинет структур: экраны

Документ для дизайна. Здесь описано, что пользователь видит и что может сделать. Детали данных: [[13_Кабинет_структур_Контракт]].

## 1. Верхняя панель

- Кнопка левого меню.
- Блок «В процессе»: какая проверка идёт, на каком шаге и сколько ещё. По клику открывается список.
- Ссылки «Вопросы» и «Слежения».
- Выделенная кнопка «Новая проверка». Она ведёт на пустой холст, где есть поле ввода и предложения.
- Название организации и профиль.
- Значок непрочитанных уведомлений.

### Левое меню

Открывается кнопкой на холсте, на страницах списков закреплено слева.

- Все вопросы, Мои, На слежении, В процессе, Без группы.
- Нарративы.
- Предложение группы: только подсказка, решение за человеком.

## 2. Холст

Холст работает как в Figma: его можно двигать, приближать и отдалять.

### Управление

| Действие              | Результат                                             |
| --------------------- | ----------------------------------------------------- |
| Перетащить фон        | Двигается холст                                       |
| Колесо или щипок      | Масштаб                                               |
| Клик по публикации    | Открывается её карточка                               |
| Клик по связи         | Показывается, что изменилось и чем связь подтверждена |
| Кнопка «Показать всё» | Всё дерево помещается на экран                        |
| Переключатель вида    | Дерево или хронология                                 |

Положение узлов выбирает система. Сотрудник может перетащить узел, но это меняет только его вид и не меняет данные.

### Виды узлов

| Узел                      | Что значит                           | Что показать           |
| ------------------------- | ------------------------------------ | ---------------------- |
| Проверяемый текст         | С чего начали                        | Цитата                 |
| Самая ранняя из найденных | Начало известной истории             | Сайт, дата, подпись    |
| Публикация                | Пересказ или новость                 | Сайт, дата, заголовок  |
| Разбор                    | Фактчекинг или опровержение          | Отдельная метка        |
| Источник не найден        | На него ссылаются, но страницы нет   | Название, без ссылки   |
| Предыстория               | Старая страница той же темы          | Приглушённый вид       |
| Новая публикация          | Появилась после последнего просмотра | Заметная метка «новое» |

### Виды связей

| Связь         | Что значит                        | Как показать   |
| ------------- | --------------------------------- | -------------- |
| Подтверждена  | Есть ссылка на странице           | Сплошная линия |
| Вероятная     | Совпал текст или есть «по данным» | Пунктир        |
| С изменениями | По дороге изменились факты        | Заметная линия |

Публикации без связи тоже важны. Их можно показать отдельной группой рядом с деревом с подписью «Связь не найдена». Такая публикация не считается ошибкой.

### Карточка публикации

- Сайт, заголовок, дата, откуда взята дата.
- Цитата.
- Ссылка «Открыть источник».
- Позиция: подтверждает, возражает, частично, нейтрально.
- Почему нет связи, если её нет.
- Что изменилось относительно родителя.

## 3. Ход поиска

Небольшой блок поверх холста. Его можно свернуть.

| Шаг           | Текст                                     |
| ------------- | ----------------------------------------- |
| Разбор текста | Выделяем утверждения                      |
| Поиск         | Ищем публикации на ro, ru, en             |
| Следы         | Проверяем ссылки и названные источники    |
| Дерево        | Определяем, кто у кого взял               |
| Стороны       | Смотрим, кто подтверждает и кто возражает |
| Готово        | Дерево построено                          |

У шага есть состояния: ожидает, идёт, готово, ошибка. Рядом можно показывать счётчики: найдено публикаций, проверено следов.

## 4. Правая панель

Панель занимает всю высоту и выглядит как лента сообщений о выбранном тезисе. В ней нет свободного чата в первой версии.

### Сообщения

| Сообщение           | Когда появляется        | Действие                  |
| ------------------- | ----------------------- | ------------------------- |
| Найдены утверждения | После разбора           | Выбрать тезис             |
| Итог проверки       | После проверки          | Открыть дерево            |
| Предложение следить | После итога             | «Следить» или «Не сейчас» |
| Слежение включено   | После согласия          | «Настроить»               |
| Уведомление         | Когда что-то изменилось | «Показать на дереве»      |
| Сводка              | По расписанию           | Открыть изменения         |

### Пример ленты

> **Итог:** источники расходятся. За 0, против 2, частично 4.
>
> Самая ранняя из найденных: moldova1.md, 4 мая 2026.
>
> **Поставить этот тезис на слежение?** [Следить] [Не сейчас]

> **Новое:** за сутки появились 5 публикаций на русском языке.
> [Показать на дереве]

### Настройки слежения

- Как часто проверять: раз в день, раз в неделю.
- Какие сигналы присылать.
- Как долго следить: 7, 30 дней или пока не выключат.
- Куда присылать: кабинет, почта.

## 5. Список слежений

Отдельный экран или выдвижная панель.

| Колонка            | Что показывает                            |
| ------------------ | ----------------------------------------- |
| Тезис              | Короткая формулировка                     |
| Состояние          | Растёт, спокойно, опровергается, затухает |
| Новое              | Сколько изменений не прочитано            |
| Последняя проверка | Дата и время                              |
| Слежение           | Вкл, пауза, выкл                          |

## 5а. Все вопросы

Все заданные вопросы сохраняются, к любому можно вернуться: дерево и прошлые проверки остаются.

- Поиск и фильтры: период, автор, язык, состояние.
- Колонки: вопрос, нарратив, число проверок, последняя проверка, состояние.
- Можно отметить несколько вопросов и нажать «Собрать в нарратив».

## 5б. Нарратив

Этап 4. Группа вопросов, собранная человеком из реальных цитат.

- Название, описание сотрудника, кто подтвердил.
- У каждого вопроса полоска долей и счёт: за, против, частично, нейтрально.
- Цитаты из публикаций.

## 6. Особые состояния

| Состояние           | Что показать                          |
| ------------------- | ------------------------------------- |
| Пустой кабинет      | Подсказка и пример                    |
| Поиск идёт          | Ход поиска и появляющиеся узлы        |
| Утверждений нет     | Объяснить, что проверять нечего       |
| Мало источников     | Показать найденное и что не проверено |
| Корень не определён | Написать это прямо, без ложного корня |
| Поиск недоступен    | Показать причину и кнопку повтора     |
| Лимит исчерпан      | Показать лимит и когда он обновится   |

## Что должно быть в дизайне

- Кабинет и пустой холст.
- Поиск в процессе.
- Готовое дерево с разными узлами и связями.
- Карточка публикации и карточка связи.
- Правая панель до включения слежения и с уведомлениями.
- Настройки слежения.
- Список слежений.
- Состояния ошибок и лимита.
- Все вопросы и нарратив.
- Левое меню и проверки в процессе.

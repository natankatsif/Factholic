# 05 — Verification: тезис + источники → оценка 0–10

**Владелец:** backend-2

Сопоставляет тезис с найденными источниками и выставляет оценку достоверности.

|        | Тип                                                                                   | Файл       |
| ------ | ------------------------------------------------------------------------------------- | ---------- |
| Вход   | `VerificationInput` (`Claim` + `FoundSource[]` + контекст)                            | `types.ts` |
| Выход  | `VerificationOutput` (score, label, тексты, stance по каждому источнику)              | `types.ts` |
| Пример | `mockVerificationInput`, `mockVerificationOutput`                                     | `mock.ts`  |
| Mock   | `STAGE_VERIFICATION=mock` → mock-функция в конце `mock.ts`                            | `mock.ts`  |
| Real   | `STAGE_VERIFICATION=real` в `.env`, нужны: `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL` | `real.ts`  |

## Шкала (score ↔ label должны совпадать)

| score  | label          | смысл                                                           |
| ------ | -------------- | --------------------------------------------------------------- |
| 9–10   | `true`         | подтверждается независимыми источниками                         |
| 7–8    | `mostly_true`  | верно, есть неточности в деталях                                |
| 5–6    | `mixed`        | частично верно                                                  |
| 3–5    | `misleading`   | факт формально верный, но подан искажённо / вырван из контекста |
| 2–4    | `mostly_false` | в основном неверно                                              |
| 0–1    | `false`        | опровергается                                                   |
| `null` | `unverifiable` | прогноз, мнение или нет данных                                  |

## Требования

- Оценивать **только по источникам**, не по «знаниям модели» — иначе нечего показать пользователю.
- Если источники противоречат друг другу → `mixed` и честно написать это в `explanation`.
- `summary` / `explanation` — нейтральный тон, на `uiLanguage`.
- `sourceAssessments` — по одной на каждый источник; источники с `relevance` < 0.3 этап 06 во фронт не отдаёт.

# 06 — Mutations: дерево → где утверждение раздули

**Владелец:** backend-2

Сравнивает структуру утверждения у родителя и потомка вдоль рёбер дерева и находит, что изменилось при перепечатке.

|        | Тип                                                                                            | Файл       |
| ------ | ---------------------------------------------------------------------------------------------- | ---------- |
| Вход   | `MutationsInput` (`Claim` + дерево из 05)                                                      | `types.ts` |
| Выход  | `MutationsOutput` (`ClaimMutation[]` из contracts)                                             | `types.ts` |
| Пример | `mockMutationsInput`, `mockMutationsOutput`; пример с раздутыми цифрами — `clm_09` в contracts | `mock.ts`  |
| Mock   | `STAGE_MUTATIONS=mock`                                                                         | `mock.ts`  |
| Real   | `STAGE_MUTATIONS=real`, нужны: `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL`                      | `real.ts`  |

## Что делать

1. Пары: каждое ребро дерева (`parentId → id`), где у обоих есть `structure` (`ClaimStructure` из 03), плюс
   корень → `"video"`.
2. Дешёвый предфильтр кодом (`diff.ts`) — кандидаты по полям:
   - `numbers` — числа сопоставляются по `about` (без регистра, по основам слов), значение разбирается из строки
     (`1 200`, `3,5 млн`, `20 de mii`, `полмиллиона`, `полметра` = `50 см`). Больше 10% — `inflated` / `deflated`,
     не разбирается и написано иначе — `changed`, число появилось / пропало — `added` / `removed`;
   - `place` — множества мест без регистра: место заменено → `changed`; добавлено к местам родителя (или родитель о месте
     молчал) → `added` — подробность, не флаг; потомок оставил часть мест или потерял все — не кандидат;
   - `time` — сутки по `time.date` (или по словам «сегодня / вчера / недавно» от даты публикации узла);
     расходятся больше чем на сутки или давнее событие подано как недавнее (`relative` при старой дате у родителя)
     → `shifted`; время словами, которых код не знает («в четверг», «третий день подряд»), — с допуском 7 дней;
   - `certainty` — `hedged` < `reported` = `asserted`: «возможно» стало фактом — `inflated`, наоборот — `deflated`.
     `reported` и `asserted` различаются только тем, назван ли источник во фрагменте (заголовок, сниппет, фраза из
     видео), — это не мутация;
   - `attribution` — оба ссылаются на источник, и источники разные (не тот же короче / длиннее, не сам родитель)
     → `changed`. Ссылка пропала или появилась — не кандидат: она может быть в соседней фразе или в титре.
   - пара корень → видео — только расхождения с первой публикацией (числа, место, время, уверенность): новость по
     дороге пополняется, где появилась деталь — видно на ребре.
     `event` кодом не сравнивается — только идёт в промпт как контекст. Нет кандидатов — пара в LLM не идёт.
3. Остальные пары — одним вызовом LLM: подтвердить или отклонить каждого кандидата (синонимы, округления,
   та же дата в другой форме — не мутация) и короткий `note` на `uiLanguage`. LLM не ответила — кандидаты кода
   с шаблонными `note` (`texts.ts`).

Этап 09 ставит флаг «раздули», если есть хотя бы одна мутация с `direction: "inflated"`.

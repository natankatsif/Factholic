# 07 — Root date: дерево → флаг «старый контент»

**Владелец:** backend-2

Сравнивает дату корня дерева с датой, которую заявляет видео. «Вчера в Кишинёве…», а первая публикация —
три года назад → флаг «Старый контент». Чистая функция без LLM и внешних API — дёшево, не переключается mock/real.

|        | Тип                                                                       | Файл       |
| ------ | ------------------------------------------------------------------------- | ---------- |
| Вход   | `RootDateInput` (`Claim` со `structure` + дерево + дата публикации видео) | `types.ts` |
| Выход  | `RootDateOutput` (`claimedAt`, `rootPublishedAt`, `flag` или `null`)      | `types.ts` |
| Пример | `mockRootDateOutput` (флага нет), `mockOldContentOutput` (флаг есть)      | `mock.ts`  |

## Что делать

1. **Заявленная дата** (`claimedAt`): `structure.time.date` (начало года / месяца / дня). Если даты нет, но
   `time.relative` — по словам `time.text` от даты публикации видео (нет — от момента анализа):
   «сейчас / сегодня / только что / acum / azi / astăzi / now / today» — тот же день, «вчера / ieri / yesterday» —
   −1 день, «на этой неделе / недавно / săptămâna aceasta / recent / this week / recently» — −7 дней.
   Ничего не узнано или времени нет — `null`, флаг не ставим.
2. **Дата корня** — `publishedAt` узла `tree.rootId`.
3. **Флаг**, если корень раньше заявленной даты больше чем на допуск: относительное время — 3 дня
   («на этой неделе» / «недавно» — 14 дней), явная дата — 2 дня. `note` — по-русски, с обеими датами.

Без даты публикации видео (её отдаёт 01 ingest) «вчера» считается от момента анализа — для свежих видео это
почти то же самое.

# AGENTS.md — packages/contracts

Общий контекст — в корневом `AGENTS.md`. Это **сетевой контракт** между бэкендом и расширением.

## Правила

1. Любое изменение здесь затрагивает и бэкенд, и фронт. Меняется **только по договорённости всех троих**;
   агент без явного указания пользователя этот пакет не меняет.
2. Предпочитай **добавление** опциональных полей переименованию/удалению — так не ломаются обе стороны сразу.
3. Изменил тип → обнови моки в `src/mocks/` (они — данные для дизайна) и проверь потребителей:
   `npm run check -- contracts backend-core extension` (pre-commit сделает это сам).
4. Только типы, чистые функции-хелперы (`formatRange`) и моки. Никаких зависимостей от Node или DOM.
5. Внутренние типы пайплайна сюда не кладём — они в `backend/src/stages/*/types.ts`.
6. Ссылки в моках выдуманы (домены настоящие ради фавиконок) — не выдавать их за реальные данные.
